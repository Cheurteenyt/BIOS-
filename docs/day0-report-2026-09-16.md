## 2. The 3644 decision tree

3644 is absent from three official ASUS ledgers and the ring-11
"3644 zip" was proven a 240-byte HTML page (`vendor-ledger-tuf.json`).

- H1 (bad acquisition): closed — the HTML page was the "3644" file.
- H2 (ledger omission): tested across PRIME 39, TUF ATX 33, TUF
  mATX 33 — empty.
- H3 (the board ships something the ledgers do not list — OEM/
  factory build): **the dump decides**. If §1 triangulates to a
  release whose version string reads 3644 or nearby, record: version
  string, AGESA level, PSP fingerprint set, NVRAM defaults — and
  re-check the ledgers with those exact values.

## 7. Honesty notes for the day

- Body-hash identity, never header bits — the "one-byte change"
  lesson is institutional.
- Names come from the join; never invented. A GUID with no name is
  recorded as a GUID — on a vendor image that means new silicon,
  itself a finding.
- Every claim cites its register; every register exists before the
  narrative that quotes it.
- The +0-octet rule is verified in §0 and stands for the whole
  session. No SPI write, no flash, no daemon, no ESP/NVRAM touch.
